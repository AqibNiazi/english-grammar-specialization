# Questions, Present Progressive and Future Tenses

Course 2 of the **Learn English: Beginning Grammar** Specialization.

## Course Overview

This course focuses on:

- Yes/No Questions
- Wh- Questions
- Question Formation
- Present Progressive Tense
- Future Tense Forms
- Using **will**, **be going to**, and the Present Progressive to talk about the future
- Grammar Accuracy and Sentence Construction

## Learning Outcomes

After completing this course, learners should be able to:

- Form grammatically correct Yes/No and Wh- questions.
- Use the Present Progressive Tense to describe actions happening now and planned future events.
- Distinguish between different future tense forms and use them appropriately.
- Construct accurate questions and responses in everyday conversations.
- Improve grammar skills for IELTS, academic writing, and professional communication.
